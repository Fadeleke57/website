# Applications

- Redteaming
- Probing
- Debugging
- Gradient-based optimization

The reason there isn't quite a one on one mapping between how LMs translate intent into work and how CPUs execute code is that LMs are probabilistic and CPUs are deterministic. Working in the prompt space of the LM is a way to bridge this gap, but current methods are not perfect.
